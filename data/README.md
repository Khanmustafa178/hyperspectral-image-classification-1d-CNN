# PaviaU Dataset

Place the two MATLAB files expected by the experiment in this directory:

```text
PaviaU.mat
PaviaU_gt.mat
```

The notebook/code expects the MATLAB variables:

- `paviaU` — hyperspectral image cube
- `paviaU_gt` — ground-truth label image

## Before publishing

Do not upload the dataset to GitHub until you have confirmed that its license/terms permit redistribution. If redistribution is not permitted, keep the `.mat` files outside the repository and document the official download source here.
